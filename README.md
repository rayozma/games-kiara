# Belajar & Bermain 🎮

First timer. Made this one for my precious. Happy playing and learning!

🔗 **Live:** https://rayozma.github.io/games-kiara

## Daftar Game

| File | Game | Isi |
|---|---|---|
| `index.html` | Menu Utama | Halaman pilih game |
| `huruf.html` | Belajar Huruf | Kenalan huruf A–Z + tantangan cari huruf |
| `angka.html` | Belajar Angka | Berhitung 1–20 + tantangan cari angka |
| `hewan.html` | Belajar Hewan | Kenalan 20 hewan + tantangan cari hewan |

## Fitur

- 🔊 Suara Bahasa Indonesia (pakai suara bawaan browser)
- 🎯 Mode "Tantangan" — anak pilih jawaban yang benar, bukan cuma dengar
- ⭐ Progres tersimpan otomatis di HP/laptop masing-masing (tidak perlu login)
- 🎵 Musik latar + tombol mute
- ⌨️ Bisa pakai keyboard (laptop) atau sentuh layar (HP/tablet)

## Cara Menjalankan di Komputer

Tidak perlu instalasi apa pun — tinggal buka `index.html` langsung di browser.

## Struktur File

```
├── index.html   → menu utama, link ke semua game
├── huruf.html   → game belajar huruf
├── angka.html   → game belajar angka
├── hewan.html   → game belajar hewan
└── bgm.mp3      → musik latar
```

Semua game adalah file HTML tunggal (HTML+CSS+JS jadi satu), jadi gampang di-upload dan di-edit satu per satu.

## Menambah Game Baru

1. Buat file `.html` baru untuk game tersebut.
2. Tambahkan satu kartu baru di `index.html` yang mengarah ke file tersebut.
3. Upload kedua file ke repo ini → otomatis muncul di menu.
